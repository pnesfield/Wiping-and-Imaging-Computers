Wiping and Imaging Computers
============================
##Diskpart

Create USBs with M/S Diskpart to boot into PXE Win PE. Useful for booting into WinPE only, 100% Microsoft tech so guaranteed to work unlike other FOSS methods

[Part6 Create a bootable USB with Diskpart to install M/S Windows](https://www.youtube.com/watch?v=MxRU0CJUDAg)
